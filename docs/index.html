Faktencheck lokal

Text auf einer Webseite markieren, Rechtsklick, Faktencheck. Die Prüfung läuft mit der in Chrome eingebauten KI direkt auf deinem Rechner – ohne Cloud, ohne Konto.

Bleibt auf dem Gerät

Der markierte Text wird von Gemini Nano in Chrome verarbeitet und nirgendwohin gesendet. Kein Konto, kein API-Schlüssel, keine Kosten.

Behauptung für Behauptung

Aus dem Text werden bis zu fünf überprüfbare Aussagen herausgezogen und einzeln bewertet – mit kurzer Begründung.

Ehrlich bei Unsicherheit

Sechs Stufen von „Stimmt“ bis „Falsch“, dazu „Nicht prüfbar“ und die Angabe, wie sicher sich das Modell ist.

Wikipedia als Beleg

Auf Wunsch zieht die Erweiterung passende Wikipedia-Artikel heran. Gesendet werden dann nur Suchbegriffe, nie der markierte Text.

Selbst nachprüfen

Zu jeder Aussage ein Klick zur Websuche und zu bestehenden Faktenchecks von Redaktionen.

Installation

  1. ZIP herunterladen und entpacken.
  2. In Chrome chrome://extensions öffnen und oben rechts den Entwicklermodus einschalten.
  3. Entpackte Erweiterung laden wählen und den entpackten Ordner angeben.
  4. Beim ersten Faktencheck einmal Lokales KI-Modell laden anklicken – Chrome lädt das Modell einmalig herunter.

Voraussetzungen

  • Google Chrome ab Version 138, für Antworten auf Deutsch ab Version 149.
  • Windows 10/11 oder macOS 13 und neuer.
  • Mindestens 22 GB freier Speicher für das Modell.
  • Grafikchip mit mehr als 4 GB Speicher – oder 16 GB RAM und 4 Prozessorkerne.
  • Welche Hardware rechnet, entscheidet Chrome: derzeit Grafikchip oder Prozessor. Eine NPU steuert Chrome für dieses Modell bisher nicht eigens an.

Hinweise

  • Das lokale Modell ist klein. Es kann sich irren und kennt keine aktuellen Ereignisse.
  • Das Ergebnis ist eine erste Einschätzung, kein Urteil. Wichtige Aussagen immer an den Quellen gegenprüfen.
